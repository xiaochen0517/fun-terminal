# 你好，终端

如果你看到这一行，说明你已经在一个终端里读博客了。这里没有导航栏，也没有侧边栏，只有一条提示符和等宽字体。

## 可以这样开始

- 输入 `help`，看看这台机器提供了哪些命令。
- 输入 `ls`，看看当前目录里有什么。
- 输入 `cat README.md`，读一读站点的第一份说明。
- 输入 `cd /mnt`，看看有哪些内容被挂载进来。

> 把内容放进终端，不是为了复古，而是想让你用「翻文件」的方式逛一个站点。

## 为什么是终端

浏览器里已经有无数种阅读体验：卡片列表、瀑布流、阅读进度条。终端给不了这些，但它给了另一种确定感：

- 输入什么，就发生什么；
- 一条命令失败，会告诉你失败在哪里；
- 目录结构就是内容结构，没有隐藏的分页与推荐位。

对一个以文字为主的个人站点来说，这种直白刚好够用。

## 后面会写什么

主要会是技术笔记、项目复盘和零散的想法。它们首先是一份 Markdown 源文件，其次才是排版后的文章：

1. 复制一份原文保存下来；
2. 在站点里按富文本阅读；
3. 用标签把相关的几篇串起来。

如果你对实现本身感兴趣，可以看看 [Vue](https://vuejs.org/) 和 [Vite](https://vite.dev/) 的文档——这个站点的界面就是用它们搭起来的。

## 一点约定

会话状态只存在于当前页面：刷新之后，当前目录回到 home，命令历史清空。这不是缺陷，而是「一次浏览」的定位。

文章会持续更新，但不会打扰你：没有订阅弹窗，也没有「猜你喜欢」。
