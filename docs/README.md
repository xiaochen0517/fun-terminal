# 文档索引

> 本文件是 `docs/` 目录下所有文档的统一索引入口。
> 查找相关文档时，请先查阅本索引，**切勿直接读取全部文档或无关文档**，避免获取过多无用信息。

## 使用说明

1. 当需求/缺陷涉及已有文档时，先在本索引中按「类型」和「文档名/标题」查找。
2. 定位到目标文档后，再读取对应文档文件。
3. 新增文档后，需在下方对应表格中添加索引记录。

## 状态说明

- `待审核`：文档已创建，等待用户审核
- `已通过`：用户审核通过，可进入开发执行
- `待验收`：开发与自动化门禁完成，等待人工页面验收
- `已完成`：开发执行完毕，且涉及 GUI 时已通过人工验收
- `已废弃`：文档作废，不再使用

> 涉及 GUI 的文档，只有人工验收通过后才可标记为「已完成」；详见 [AGENTS.md](../AGENTS.md) 第三节。
